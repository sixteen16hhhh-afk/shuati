题目格式说明

每道题以“题号.”开头，选项用 A–F（大小写都可以，可竖排也可写在同一行），答案写在【答案】后面，解析写在【解析】（或【xx解析】）后面，可以不写。

一、单选题
1.题干（　）
A 选项一
B 选项二
C 选项三　D 选项四
【答案】C
【解析】……

二、多选题
1.题干（　）
A 甲　B 乙　C 丙　D 丁
【答案】ABD

三、判断题
1.题干。
【答案】对        ← 也可写 错 / √ / × / A（对）/ B（错）

8.【材料】一段材料……
8.1 第一小题（　）
A …… B …… C …… D ……
【答案】A
8.2 第二小题……
  • 题型自动识别：没有选项且答案是 对/错/√/×/A/B → 判断题；答案有多个字母，或在“多选题”标题下面 → 多选题；其余是单选题。
  • “一、单选题 / 二、多选题 / 三、判断题”这样的标题会帮助识别题型。
  • 材料题：“8.【材料】……”后面的 8.1、8.2 小题都会显示这段材料。单独一行“【材料】……”的材料会作用到后面所有题，直到遇到新的材料、新的大题标题或“【材料结束】”。
  • 也支持 JSON：{"name":"题库名","questions":[{"type":"single","stem":"…","options":["…","…"],"answer":"A","explanation":"…","material":""}]}，type 可选 single / multi / judge，判断题 answer 写 true / false。
  • 末尾空白的选项（比如只写了个“D”）会被自动忽略。
